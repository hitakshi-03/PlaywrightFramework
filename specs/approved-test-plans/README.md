# Approved Test Plans

Start with the [review index](./index.md) for the current approval status of each candidate. Plans are not automatically approved.

Plans awaiting review must use `PENDING HUMAN APPROVAL`.

Generator may read a plan only when an authorized human has marked it `APPROVED` and recorded:

- approver
- approval date
- approved scenario IDs
- scope/environment constraints

Rejected and deferred plans must remain documented here or in a linked review record, with reasons.
